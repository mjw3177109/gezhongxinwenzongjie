# 投资研究版 V2｜如何真正生成中文内容总结和大师框架分析

本版已经改成**正文证据 → 投资委员会总结 → 邮件正文**。不再把新闻链接清单当作分析结果。

## 投资人视角的固定输出

- **核心观点**：5-6条当天重要事件、实体和传导机制，带新闻出处。
- **十大事件深读**：发生了什么（中文内容总结），为什么影响利润/现金流，哪些行业或公司可能受影响，多种分析框架的判断，哪部分尚未核实。
- **投资框架**：巴菲特（护城河/现金流/估值）、芒格（反向思考/激励）、达利欧（债务与货币周期）、索罗斯（预期差与反身性）、彼得·林奇（需求和成长）、霍华德·马克斯（周期风险）。
- **跨行业链条**：利率→融资→资本开支→供需/利润率等，必须有证据。
- **反方观点与观察清单**：多空情景、验证条件、接下来跟踪哪些可观测数据。

这只是**用知名投资者的方法分析**，并不是假冒他们本人提供观点。没有实时市场价格和财务指标时，禁止轻易断言“便宜”“马上买入”。

## 重要：目前你的仓库只配置了 QQ 邮箱密钥，AI Key 仍须配置

源码会真实尝试抓取新闻正文，从标题扩展到更多事实线索，但**跨语种中文综合归纳和深入投资研判离不开真正的模型 API**。GitHub Actions 并不自带免费的新闻分析模型；GitHub Models 已于 2026 年 7 月停止服务。

**建议使用 DeepSeek API：**

1. 到 [DeepSeek 官方 API 平台](https://platform.deepseek.com/) 生成 API Key。调用可能产生费用。
2. 打开仓库 [Actions Secrets 配置](https://github.com/mjw3177109/gezhongxinwenzongjie/settings/secrets/actions)，新建（不要写在源代码中）：
   - Secret: `OPENAI_API_KEY` = 你的 DeepSeek API Key
3. 打开仓库 [Actions Variables 配置](https://github.com/mjw3177109/gezhongxinwenzongjie/settings/variables/actions)，新增：
   - Variable: `OPENAI_API_URL` = `https://api.deepseek.com/chat/completions`
   - Variable: `OPENAI_MODEL` = `deepseek-v4-flash`（以官方当前可用模型为准）
4. 完成后在 [Actions](https://github.com/mjw3177109/gezhongxinwenzongjie/actions/workflows/daily-report.yml) 手动执行一次。**同一天如果已有日报，将跳过重建；想要验证新版需勾选 force。**注意同一天已记录邮件回执的日报不会自动重发，以免重复骚扰邮箱。
5. 观察 `reports/年/月/日/investment-brief.md` 的研究元数据及正文是否出现具体投资分析，而不再只有“尚未完成模型深度归纳”。

**也可以使用 OpenAI Chat Completions**，只配置 `OPENAI_API_KEY`，`OPENAI_API_URL` 默认 `https://api.openai.com/v1/chat/completions`，`OPENAI_MODEL` 默认 `gpt-4.1-mini`。

## 证据覆盖及可信度

系统最多选择 26 篇跨行业重要事件，优先可信发布方直接网页和经济影响较大的信息。
尝试从公开网页读取不超过有限长度的文章证据，遇到付费墙/反爬/无法解析时退回 RSS 描述，仍无法取得则标注为“仅标题”。
投资分析阶段要求标注新闻出处，参考内容不等于原文已事实核查。新输出的“事实”与“投资假设”需明确区分。

尽管整库可以收集数百条新闻，**AI 深读的是精选五到数十篇，并不是把数百篇全文全部阅读**。想增加数量可以设置 `INVESTMENT_ARTICLES`（默认 26，建议不超过 35；增大会提高耗时和 API 成本）。

## 文件、邮件

- `investment-brief.md`：**重点阅读**，投资研究报告与关键新闻证据
- `report.md`：投资晨报开头 + 所有行业与地区新闻附录
- `sources.csv`：完整来源检索
- `data.json`：统计、内容研究元数据及原始 RSS 摘要
- 邮件**正文改为 investment-brief.md**，并附加完整日报、投资晨报和来源 CSV。

## 失败处理

- AI Key 未配置、欠费、模型输出不合规或请求失败时：邮件中**明确标注**不含专家研判，保留具有来源的新闻证据；不制造不存在的摘要。
- RSS 全部没有有效数据时：主动失败，不发假报告。
- 支持同日文件跳过，避免重复发送；强制刷新只改当日报告，已有邮件回执时不会重复投递。
- 原文网页由新闻网站控制，提取可能失败；不绕过登录和付费限制，不复制新闻全文到公开仓库。
- 不提供个性化投资建议或买卖指令；决策前请结合财报、估值、市场数据和自身风险承受能力。
