# 全球全行业每日情报（Global Daily Intelligence）

每天自动采集全球多地区、多行业新闻，优先读取公开文章正文，借用巴菲特、芒格、达利欧、索罗斯、林奇和霍华德·马克斯的投资框架生成**中文投资委员会晨报**，并归档到 GitHub、通过 SMTP 邮件发送。

**状态说明：** 工作流在代码提交到默认分支后按计划触发；首次启用邮件必须配置 GitHub Actions Secrets，详见 [小白使用说明](docs/小白使用说明.md)。未配置邮件服务时仍会保存日报，但不会声称邮件已发送。

## 每日定时
默认北京时间 **08:17（UTC 00:17）**，每天一次。支持 Actions 页面手动运行。新闻窗口为运行时向前 24 小时，日期按北京时间归档。GitHub 的定时作业可能延迟或偶发被跳过。

## 归档结构

```text
reports/
  2026/
    10/
      21/
        investment-brief.md # 中文投资晨报与核心新闻内容总结（优先阅读）
        report.md           # 投资研究 + 行业地区原始消息附录
        data.json           # 结构化新闻及统计
        sources.csv         # 新闻标题、媒体、时间、链接
        mail-sent.json      # 成功发送邮件后写入（不含账号密码）
```

## 功能边界
- 约 30 个行业和区域观察主题；多语言检索与公开 RSS 来源。广覆盖不代表采集全世界所有媒体。
- **V2 投资版：** 从公开发布方网页提取可获得的正文证据，针对约 26 篇跨行业核心事件生成投资研究摘要；基于模型生成中文投资分析，覆盖事件总结、商业逻辑、宏观周期、反方论据与后续验证指标。
- **重要：** 没有模型 API Key 时，只提供原文证据摘录和投资核验方向，不能生成可靠的中文深度分析。具体配置：[投资研究版配置.md](docs/投资研究版配置.md)。
- 过滤过期/重复报道，记录来源故障、样本规模。若没有数据则明确标注抓取失败，不生成假新闻。
- 报告按日期归档，同日默认不覆盖；可手工触发强制刷新。
- 邮件正文直接展示投资委员会晨报，另附完整日报、投资简报及来源 CSV；用 SMTP 发送。密钥只放 GitHub Secrets，不写进仓库。
- 所有抓取结果均为信息摘要，不转载付费全文；涉及投资、医疗、法律等领域不构成专业建议。

## 立即配置
请查看 **[docs/小白使用说明.md](docs/小白使用说明.md)**，配置 SMTP 收发件人及应用密码。若希望获得用户要求的中文深度总结和投资大拿分析框架，**必须配置模型 API Key**，可选 DeepSeek V4 Flash 或 OpenAI，详见 [投资研究版配置](docs/投资研究版配置.md)。不配置时依然收集新闻与有限正文证据，但不会冒充完成专家研判。

## 程序
```bash
python -m unittest discover -s tests -v
python src/daily_digest.py
python src/send_email.py
```

本项目使用 Python 标准库，无需额外安装 pip 依赖。新闻正文提取仅限可访问网页，部分媒体页面提取失败会主动标明证据等级。

## 声明
Google News RSS 属于未承诺 SLA 的公开聚合入口，内容可能受搜索可用性、地区、版权及服务策略影响。自动化需接受 GitHub Actions 配额及定时行为约束。
